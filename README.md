# Customer Churn Prediction & Retention System

## Project Overview
This project focuses on predicting customer churn using Machine Learning and identifying customers who are likely to leave a service.

The system helps businesses understand customer behavior, identify high-risk customers, and support customer retention strategies.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Joblib

## Dataset
The project uses the IBM Telco Customer Churn dataset containing customer information, service details, account information, and churn status.

## Project Workflow
1. Data Loading and Understanding
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Training and Comparison
6. Model Evaluation
7. Customer Churn Prediction
8. Customer Retention Insights

## Machine Learning Model
- Random Forest Classifier

## Application Features
- Executive Overview
- Customer Analytics
- Churn Prediction
- Revenue Risk Analysis
- Model Performance
- Customer Lookup

## Model Performance
Champion Model: Random Forest

ROC-AUC Score: 0.8406

## How to Run

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Run the Streamlit application:

   `streamlit run app_predict.py`
